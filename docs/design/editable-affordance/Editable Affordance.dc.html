TURN 1 — CORNER-MARKED EDITABLE TEXT
Editable affordance
Five marker treatments, each drawn only at the corners of the run's own bounding box, so the extent of what is editable is stated without touching the type. Text stays the surrounding text: same face, same size, same colour, same rhythm. Hover any specimen.
Markers are pure background layers — no wrapper box, no shifted baseline. Horizontal padding is cancelled by equal negative margin, so inserting one never reflows the line.

HOW IT IS BUILTMarkers are background layers on the span itself — four radial gradients for dots, eight linear gradients for chevrons. No pseudo-elements, so it survives inside links, table cells and headings, and box-decoration-break: clone gives every wrapped fragment its own corners.
WHY NO REFLOWVertical padding on an inline box does not affect line height, and horizontal padding is cancelled by equal negative margin. Turning the affordance on or off never moves a glyph, which is the property a hyperlink has and a form field does not. Horizontal padding is capped below half the word space of the surrounding type — 1px at 15px body, 4px at 38px display — so adjacent runs never overlap. Under about 5px of word space the break between two runs stops being legible; see 1g.
OPEN QUESTIONWhether corners should be visible at rest at all, or only under an edit mode. 1e assumes always-visible but demoted; the alternative is nothing until the mode is armed, which reads cleaner and teaches nothing.
