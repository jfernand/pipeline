# Principles

These are the principles that guide the development of this project. They supercede all other considerations.

## Priorities

The most important priorities are:
1. Correctness
2. Performance
3. User experience
4. Developer experience

Good quality code is essential to uphold those prioriti3es.

### Security

Security is correctness.

### Performance

As fast as possible, unless it is not correct or too expensive. Performance is always necessary.
Performance is a part of user experience.

## Metrics

See Goodhart's Law.

## Exclusions

No boxchecking. We do not do things just because it checks a box. We do things for the right reasons.

## Feature centers

This product is centered around several pillars, from which each feature emanates. We prioritize features that align 
with these pillars over features that do not.
